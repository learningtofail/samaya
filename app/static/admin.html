Events and messages
EventScheduleAlliancesRemindersStatusActions
About this tab

An event is anything the bot posts on a schedule. Give it a duration and it also becomes a Discord Scheduled Event and shows on the public calendar. Leave the duration off and it is a message only.

  • Repeating events ask what you are editing: just one date, this date and every later one, or all of them.
  • Reminders post to the audiences each alliance uses by default. Untick an audience on the event to skip it, or tick another to add it. Alliances and audiences that share a channel get one combined message.
  • Reminder messages. Each reminder can have its own text, such as "Starting now!" for the reminder at the start. A reminder with no text posts the event message. A reminder's own text goes to every alliance and replaces an alliance's own message for that reminder.
  • Leadership only events never create a Discord Scheduled Event and never appear on public pages.
  • Deleting an event also removes its Discord events. Deactivating stops all posting but keeps the event.

About this tab

Every Discord post the engine makes or tries to make, one row each. Upcoming lists pending and sending posts, soonest first. Past lists posted, failed and cancelled posts, newest first, within the look-back window. The Detail column says why a post failed or what happened.

  • Retry puts a failed post back in the queue. It only works while the event has not started and is not cancelled.
  • Needs attention means there are errors in the last 7 days or a post has waited more than 5 minutes.

About this tab

A type is a starting point for new events: a color and the duration, repeat interval, message, reminders and role mention a new event of that type begins with. Changing a type never changes events that already exist.

Types belong to a kingdom and are shared by every alliance in it. A type that events still use cannot be deleted. Creating and editing types needs kingdom coordinator access.

Feedback

View

About this tab

What the community sent through the public feedback page. Open a ticket to see its details and the private contact the submitter left.

  • Responses are public. Anyone on the feedback page can read them, under your display name or "Team".
  • Dismiss hides a ticket from the public page without deleting it, and Restore brings it back. Only a superadmin can delete one for good.
  • Edit fixes the title, text or type, for example to remove personal details. The submitter is not told.
  • Done and declined tickets are grouped as Archived.
  • Tags, checklists and internal notes are for the team only and never reach the public page. A ticket can carry up to 8 tags, 50 checklist items and notes written in Markdown. The Tag filter applies to both List and Board.
  • Export downloads every ticket, dismissed ones included, as one JSON file or as a zip of Markdown files. Submitter contact details are left out unless you tick the box. Each export is recorded in the audit log.
  • Column limits (superadmin, Board view) cap how many tickets a column should hold. Moving a card into a full column asks you to confirm, and the override is recorded in the audit log. The status menu in List view is not limited.
  • Board shows one column per status. Use a card's Move menu (keyboard and touch), or drag it with a mouse. Moving a card changes its public status, and a move into Done or Declined asks first because it closes voting. Dismissed tickets are not on the board; use List to see them.

Audiences

About this tab

Your own settings come first. Superadmins also see access, kingdoms, Discord servers, alliances and users below them.

  • An alliance that uses no audience by default cannot receive reminders. Tick it under "Alliances that use this audience" when you edit an audience, and use "Post by default" for the ones its events should post to.
  • When two alliances, or two audiences, post to the same channel at the same offset, the engine sends one message that mentions each role once.
  • Discord Scheduled Events are created only on an alliance's primary server. An audience can post messages to any server of the Kingdom.
  • If Discord cannot be reached, the pickers turn into plain boxes where you can type the numeric ID.
  • A role or channel ID is the long number Discord shows when developer mode is on.
