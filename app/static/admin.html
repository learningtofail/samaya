About this page

Alliance filter

Shows every alliance you have access to at once by default. Narrow it to one alliance if you only want that alliance's status, events, and delivery numbers.

Sections

  • Status cards — whether each alliance's Discord bot is connected, and when its 28-day occurrence window last regenerated.
  • Regenerate Now — rebuilds the occurrence window immediately instead of waiting for the automatic daily run at UTC 00:00. With "All" selected, this runs once per accessible alliance.
  • Today's Events / Upcoming (Next 48h) — a quick look at what's coming up, pulled from the Schedule tab's own data.
  • Delivery Health — a rolling 7-day count of successful vs. failed Discord posts, split between announcements and event posts, per alliance.

Known limitations

  • Delivery Health only looks back 7 days — older failures won't show here (check Post Log or Sync for history).
  • The sync-issue banner above only appears after you've run a Sync check at least once this session.

About this page

Alliance filter and layout toggle

The Alliance filter applies to both layouts — Table and Timeline are two views of the same 28-day occurrence window, so narrowing one narrows the other. Table and Timeline share one Refresh; switching layouts is instant and doesn't re-fetch.

Sections

  • Table — Post? checkbox controls whether an occurrence will actually go to Discord; unchecking it skips that one occurrence without deleting anything. Post Selected to Discord posts every checked row in that section (Alliance or Leadership) one at a time. Cancel (on a posted row) removes the Discord Scheduled Event; the occurrence itself stays and can be posted again later.
  • Timeline — a visual Gantt-style grid grouped by event name across the next 28 days. Hover a filled cell for its exact time (both UTC and your local time zone).

Known limitations

  • This window only ever covers the next 28 days — it's rebuilt from Events daily, or on demand from the Dashboard's Regenerate Now.
  • Timeline is read-only — post/cancel actions are only available from the Table layout.

Discord Sync

Compares PostLog against live Discord events. Run manually whenever you suspect a mismatch. Field-level changes made directly in Discord are only visible here — they are not detected automatically.

Click "Run Sync Check" to fetch current Discord events.

About this page

Sections

  • Mismatched — the event exists on both sides, but a field on Discord no longer matches what's in Samaya. Push to Discord overwrites Discord's copy with Samaya's.
  • PostLog Only — Samaya thinks it posted this, but it's gone from Discord (deleted manually). Mark Cancelled just updates Samaya's own record to match reality.
  • Discord Only — exists on Discord but Samaya has no record of it (created manually). Acknowledge adopts it into PostLog so Sync stops flagging it.
  • Matched — everything agrees; collapsed by default since there's nothing to act on.

Known limitations

  • This is a manual, on-demand check — it doesn't run automatically, and nothing here is fixed until you click one of the action buttons.
  • With "All" alliances selected, this queries every alliance's Discord server in one pass, which can take longer than checking a single alliance.

Alliance filter

Narrows the Announcements list below to one alliance's own announcements (matched by its Targets). Templates aren't alliance-scoped, so the filter doesn't affect the Templates table.

Sections

  • Templates — reusable starting points; "Use" pre-fills a new announcement, it doesn't schedule anything by itself.

  • The 2000-character limit on the Body field is Discord's own message limit, not something this app can raise.
